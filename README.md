# Callscape

Generates a navigable, local HTML call graph of a repo (Python/JS/Go via tree-sitter) with click-through to function bodies and struct definitions. Fills the gap between IDE 'find references' and heavyweight code-intelligence platforms.

## Install

```bash
pip install -e ".[dev]"
```
